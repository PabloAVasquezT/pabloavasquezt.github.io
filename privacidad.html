Política de privacidad – Salud en Corto Uploader

Última actualización: 28 de octubre de 2026

Qué hace la aplicación

Salud en Corto Uploader es una herramienta de uso personal del propietario del canal de YouTube "Salud en Corto". Sirve para subir videos al canal y configurar su título, descripción, etiquetas, visibilidad y fecha de publicación mediante la API de datos de YouTube.

Datos a los que accede

Con la autorización del propietario, la aplicación accede a su cuenta de YouTube únicamente para subir y administrar los videos de su propio canal. Los tokens de acceso se guardan solo en el computador del propietario y no se envían a terceros.

Uso y divulgación

La aplicación no recopila datos de otras personas, no vende ni comparte información y no muestra publicidad. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde la configuración de seguridad de la cuenta de Google.

La aplicación usa los Servicios de API de YouTube; consulta las Condiciones del servicio de YouTube y la Política de privacidad de Google.
